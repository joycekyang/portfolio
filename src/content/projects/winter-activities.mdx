## Project Overview

I started by building out the organizational sections and individual lessons to ensure a logical flow of information, finalizing the build by adding titles, populating lessons with text, and layering in visual assets for a consistent and professional aesthetic.

## Learner Interactions

* **Generative AI Visual Carousel:** For the "Winter Activities" section, I leveraged Generative AI (Gemini) to produce a cohesive set of high-fidelity images. Through precise prompt engineering, I ensured a consistent visual style across the series, which I then added to a responsive carousel interaction to maintain high learner engagement alongside descriptive text explaining each image.
* **Custom HTML Blocks via Mighty Integration:** Used the Mighty Interactive HTML block to showcase additional Winter Activities generated through AI-assisted HTML prototyping, expanding beyond standard Rise templates.
* **Embedded Articulate Storyline Block:** Incorporated a custom Articulate Storyline block directly into Rise to create an engaging Click-to-Reveal interaction.
* **Themed Labeled Graphic:** Included an interactive Labeled Graphic and customized the color scheme with Mighty, pairing a soft winter blue background with cohesive imagery.
* **Application Branching Scenario & Assessment:** Guided the learner through a realistic scenario where they apply what they learned to help a friend plan a winter activity based on their preferences, followed by 3 assessment questions (requiring an 80% passing score) and a final summary.

## Takeaways

Creating this course was a significant learning milestone that allowed me to push the boundaries of standard authoring tools. Specifically, leveraging Mighty blocks to incorporate custom HTML and create original image blocks helped me transform a standard responsive layout into a unique, high-fidelity experience. This process greatly enhanced my technical proficiency in extending Articulate Rise with custom interactions and Storyline embeds.
